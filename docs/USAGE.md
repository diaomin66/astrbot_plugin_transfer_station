# 使用、部署与故障排查

## 1. 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 插件总开关 |
| `enabled_group_ids` | `[]` | 群号白名单；空列表表示全部群 |
| `welcome_content` | 内置欢迎文案 | 支持 `{claim_phrase}` 占位符 |
| `claim_phrase` | `领取新人礼` | 新人必须准确发送的口令 |
| `mention_new_member` | `true` | 欢迎消息是否自动 `@新人` |

配置修改后在 AstrBot WebUI 重载插件。

## 2. 兑换码管理

从插件详情打开 **新人礼管理**：

1. 每行粘贴一个兑换码并导入。
2. 空行和重复兑换码会被跳过。
3. 库存中的兑换码默认遮罩，可单独显示或复制。
4. 只能删除尚未发放的库存兑换码。
5. 已发放记录只显示兑换码尾号，完整兑换码不会继续保存。

## 3. 领取判定

一次领取必须同时满足：

1. 消息来自启用的 QQ 群。
2. 发送者曾在当前群触发 `group_increase` 入群事件。
3. 消息包含对当前机器人的 `@`。
4. 除该 `@` 外只有纯文本领取口令，不包含额外文字、图片或其他成员的 `@`。
5. 该 QQ 号从未在任何群成功领取。
6. 库存至少有一个兑换码。

## 4. 数据与备份

数据文件：

```text
data/plugin_data/astrbot_plugin_transfer_station/gifts.db
```

停用或停止 AstrBot 后复制该文件即可备份。恢复时应先停止 AstrBot，再将备份文件放回原路径。

数据库包含：

- 新人资格：群号、QQ号、入群时间。
- 未领取兑换码：完整兑换码和导入时间。
- 领取记录：QQ号、领取群、领取时间、兑换码尾号和摘要。

## 5. QQ 群临时会话要求

- AstrBot 必须使用 `aiocqhttp` 连接 NapCat。
- NapCat 必须能收到群成员增加通知。
- QQ 账号及新人隐私设置必须允许群临时会话。
- 插件调用 `send_private_msg` 时会同时传入 `user_id` 和 `group_id`。

若发送失败，群内会提示检查隐私和临时会话设置，兑换码会回滚到库存。

## 6. 常见问题

### 新人入群没有欢迎消息

检查：

- 插件是否启用。
- 群号是否被 `enabled_group_ids` 排除。
- NapCat 日志中是否收到 `notice_type=group_increase`。
- AstrBot 平台是否为 `aiocqhttp`。

### 新人提示没有资格

只有插件实际收到入群事件后才会记录资格。插件安装前的旧成员不会自动补录。

### 临时会话发送失败

检查 QQ 隐私设置、NapCat 登录状态和 OneBot 日志。发送失败时不会消耗兑换码。

### 网络超时后的风险

按当前业务策略，任何发送异常都会回滚库存。如果 QQ 端已经送达但 NapCat 响应超时，同一兑换码可能再次被分配。运营人员应结合 NapCat 日志及时核查异常。
